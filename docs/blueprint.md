# **App Name**: Abrazos Digitales

## Core Features:

- Informational Content: Provide comprehensive information about adolescent suicide prevention, including risk factors, warning signs, and ways to seek help.
- Interactive Self-Assessment: Allow teenagers to perform an interactive self-assessment test to check if they show signs of being at risk.
- Resource Directory: List of local and national resources, including crisis lines, mental health services, and support groups, with contact information and website links.
- AI-Powered Empathetic Responses: Utilize generative AI to offer empathetic, personalized responses to user inquiries, directing them towards helpful resources and coping strategies. The AI will function as a tool, using reasoning to assess if the content is useful for the given response.
- Success Stories: Share anonymous success stories of adolescents who have overcome suicidal thoughts, to offer hope and encouragement.
- Expert Q&A: Offer a question and answer feature where teenagers can ask questions to mental health professionals.

## Style Guidelines:

- Primary color: Soft Lavender (#D0B4DE) to evoke calmness and empathy.
- Background color: Off-White (#F8F8FF) to provide a clean and soothing backdrop.
- Accent color: Pale Lilac (#E6DFF3) for subtle highlights and interactive elements.
- Body and headline font: 'Alegreya', a humanist serif, for an elegant, intellectual, contemporary feel.
- Use delicate line icons in the lavender and lilac tones to represent different sections and topics.
- Implement a clean, modern layout with plenty of white space to avoid feeling overwhelming.
- Subtle fade-in animations and smooth transitions to create a welcoming and comforting user experience.
